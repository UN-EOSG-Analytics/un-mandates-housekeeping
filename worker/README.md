# PPB DOCX Worker

Azure Python Worker for processing DOCX documents in the PPB (Programme Budget) system.

## Setup

The module is configured in `pyproject.toml` with the following structure:

```
worker/
├── pyproject.toml          # Python project configuration
├── requirements.txt        # Generated dependencies (auto-generated by uv)
└── ppb-docx-worker/        # Main module
    ├── __init__.py         # Package initialization
    └── main.py             # Main entry point with CLI and Azure Function handler
```

## Installation

From the project root:

```bash
uv sync
```

## Usage

### Command Line

```bash
ppb-docx-worker
```

### Azure Function

The `main()` function in `main.py` serves as the Azure Function handler.

## Development

Update dependencies in `pyproject.toml`, then regenerate `requirements.txt`:

```bash
uv export --project worker --format requirements-txt --output-file worker/requirements.txt
```

## Dependencies

- `azure-storage-blob` - Azure Blob Storage SDK
- `psycopg[binary]` - PostgreSQL database adapter
- `python-docx` - DOCX file processing
